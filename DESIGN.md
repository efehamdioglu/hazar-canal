# DESIGN.md — Hazar Canal

Rules for every design change in this repo. Read this before touching `build.py` or
`site/assets/style.css`. If a request conflicts with a rule here, say so before building.

## 0. What this repo is (audit, 2026-11-27)

- **No `package.json`, no Tailwind, no `globals.css`, no React, no shadcn/ui.** The site is
  static HTML generated by `build.py` (Python, no dependencies), styled by one hand-written
  stylesheet, `site/assets/style.css`, with one script, `site/assets/app.js`.
- The role of `globals.css` is played by the `:root` block in `site/assets/style.css`.
- The role of a component library is played by the Python functions in `build.py` plus the
  CSS classes they emit (section 4).
- Do not add a framework, a bundler or a CSS library to satisfy a rule in this file. If the
  project ever moves to React + Tailwind + shadcn/ui, rewrite sections 0 and 4 first.
- Pages are regenerated with `python build.py`. Never edit `site/*.html` by hand.

## 1. Fonts

| Role | Family | CSS variable | Used for |
|---|---|---|---|
| Display | Bodoni Moda | `--display` | Perfume names, section headings, italic taglines |
| Body | EB Garamond | `--prose` | Running text, stories, quiz options |
| UI | Jost | `--ui` | Labels, buttons, navigation (always uppercase, letter-spaced) |
| Mono | DM Mono | `--mono` (not yet defined) | Reserved for codes, batch numbers, prices in tables |

- **Never use: Inter, Roboto, Open Sans, Arial, system-ui** — not as a primary font and not
  as a fallback. Fallbacks are the generic keyword only (`serif`, `sans-serif`, `monospace`)
  or a same-genre face (Didot, Georgia).
- No mono text exists on the site today. Add `--mono` and load DM Mono only when the first
  real mono use appears; do not load it speculatively.
- Every font must cover Turkish (ş ğ ı İ ç ö ü). Check before proposing a new one.
- The page is `lang="tr"`, so uppercase transforms turn `i` into `İ`. Foreign words that are
  uppercased (Devil, Extrait de Parfum, Unisex, English note names) must be wrapped with
  `lang="en"`: use `tx()` in `build.py:44` and the `EN_WORDS` set above it.

## 2. Color

All color is a CSS variable. No raw hex values in component rules.

| Variable | Value | Role |
|---|---|---|
| `--bg` | `#0a0908` | **Dominant.** Page ground |
| `--bg-2` | `#13110f` | Raised surface on the dominant |
| `--ink` | `#ebe5d9` | Text on dark |
| `--mute` | `#a39b8e` | Secondary text on dark |
| `--line` | `rgba(235,229,217,.15)` | Hairlines |
| `--bone` / `--bone-ink` / `--bone-mute` | `#e9e2d4` / `#15120f` / `#6a6257` | Inverted section (the dominant, flipped) |
| `--accent` | `#c9c2b2` by default | **The one accent slot** |

- **One dominant, one accent.** The dominant is warm black; `--bone` is its inversion, not a
  second color. There is exactly one accent variable, `--accent`.
- `--accent` takes its value from the perfume in scope via `[data-p="…"]`
  (the `[data-p]` block in `style.css`): Atlas `#d3a868`, Devil `#e0203c`, Barbaros `#3fc2bd`,
  Şahmaran `#dcae45`, Arora `#9d8bff`. A page or a card shows one perfume's accent at a
  time. Never place two accent values inside the same component.
- Accent is for small things: a rule, a label, a hover, a single word. Never a background
  fill larger than a button.
- **Banned: purple or indigo gradients on white.** More broadly, no decorative gradients at
  all. The only gradients allowed are the black scrims over photos and video that keep text
  readable. Arora's violet is a flat accent on black and stays that way.
- New perfume = one new `[data-p]` line setting `--accent`. Nothing else.

## 3. Spacing and type scale

**Spacing: 8px rhythm.** Every margin, padding and gap is a multiple of 8px
(0.5rem steps: 8, 16, 24, 32, 48, 64, 96, 144). 4px is allowed only inside a control
(icon-to-label gap). Fluid values use `clamp()` whose min and max are both on the grid.

**Type: extremes, not steps.**

- Weight: use the ends of the range, **200 against 800**. No 500/600 "medium" headings.
  Light end: Jost 200, only at 20px and above. Heavy end: Bodoni Moda 800. Bodoni Moda has
  no weight below 400, so its light voice is the 400 italic.
- Size: adjacent levels differ by **3x**, not 1.5x. The scale is
  `12 → 20 → 60 → 180` (label → body → heading → hero name). Nothing in between: if a size
  feels needed between two steps, change weight, case or tracking instead.
- Exactly four `font-size` values exist in the stylesheet: `.75rem`, `1.25rem`,
  `clamp(2.5rem, 4.2vw, 3.75rem)` (heading: 40px on phones, 60px on desktop) and
  `clamp(3rem, 12.5vw, 15rem)` (hero name: 180px at 1440, up to 240px). Do not add a fifth.
- Labels are 12px Jost uppercase with 0.24–0.3em tracking. Body is 20px EB Garamond at
  1.6 line-height, max 34–46ch.
- Uppercase display lines need line-height ≥ 1.08 so the dot of `İ` and the cedilla of `Ş`
  do not collide with neighbouring lines.

## 4. Components — reuse, do not hand-roll

There are no shadcn/ui primitives in this repo. These are the real ones. Call the function;
do not paste its markup.

**Python builders (`build.py`)**

| Component | Where | Use it for |
|---|---|---|
| `page(fname, title, desc, body, accent, cur, ogimg)` | `build.py:289` | Every page shell: head, fonts, header, footer |
| `header(cur)` / `footer()` | `build.py:220`, `:268` | Never write navigation by hand |
| `buy(p, first_solid, only_first)` | `build.py:206` | Every purchase button. Handles the TR / INT store split |
| `ext(href, label, cls)` | `build.py:202` | Every external link (adds `rel`, new-tab note for screen readers) |
| `notes_inline(ns)` | `build.py:216` | Dot-separated note lists on cards |
| `invite()` | `build.py:325` | The quiz call-to-action band |
| `film(...)` inside `home()` | `build.py:361` | Video tile with caption |
| `im()`, `vid()`, `poster()` | `build.py:54-63` | Every media URL. Never hard-code a media path |
| `tx()`, `brandfix()` | `build.py:44`, `:48` | Text that is uppercased and not Turkish |

Data lives in the `P` list (one dict per perfume) and `QUIZ` / `WEIGHTS` / `RESULTS`.
A new perfume is a new dict, not new markup.

**CSS primitives (`site/assets/style.css`)**

| Class | Notes |
|---|---|
| `.wrap` | Page gutter and max width. Every section uses it |
| `.sec`, `.sec--bone` | Section rhythm; `--bone` flips the palette |
| `.label` | The only small-caps text style |
| `.display` + `.h-hero` / `.h-head` / `.h-sub` | The only heading styles: hero name, heading (60), 20px tracked sub-heading |
| `.italic`, `.lede` | Tagline and intro paragraph |
| `.btn`, `.btn--solid`, `.btn-row` | The only buttons |
| `.tlink`, `.tlink--back` | Text link with arrow |
| `.badge`, `.seal`, `.chips`, `.ticks` | Small metadata |
| `.relic`, `.edp`, `.film` | Product card on bone, image card, video tile |
| `.split`, `.craft`, `.story`, `.love` | Two-column layouts |
| `.pyramid`, `.facts`, `.gallery` | Notes, spec list, image grid |
| `.seg`, `.sound`, `.buybar`, `.sister`, `.opt` | Store toggle, audio toggle, mobile buy bar, prev/next, quiz option |

**Behaviour (`site/assets/app.js`)** is attribute-driven: `data-set-store`, `data-store`,
`video[data-src]`, `.rv` (reveal), `aria-controls="mega"`. Use those hooks; do not write a
second observer or a second toggle.

If something is missing from these tables, add one primitive and list it here, then use it.

## 5. Forbidden

- **Three rounded cards in a row.** No `border-radius` on cards, images or buttons; corners
  are square. The only radius in the system is the `.seal` pill and its dot. A row of three
  equal items is allowed only for the three Extrait bottles, where the count is the content.
- **Centered-everything heroes.** Heroes are bottom-left anchored with the name bleeding to
  the edge. Centered text is allowed in one place only: the closing sign-off (`.outro`).
- **0.1-opacity drop shadows on everything.** There is no `box-shadow` in the stylesheet.
  Keep it that way. Depth comes from hairlines (`--line`), surface change (`--bg-2`) and
  photo scrims.
- Also banned: emoji as icons, decorative gradients, glassmorphism panels, pill-shaped
  buttons, stock photos of ingredients, autoplaying sound, a second accent color.

## 6. Audit status

The first audit (2026-11-27) found six breaches. Five were fixed the same day:

| Finding | Status |
|---|---|
| Arial and Helvetica in the `--ui` font stack | Fixed. Stacks end in a generic keyword only |
| Display and UI weights at 500 | Fixed. Only 200, 400 (body, italic) and 800 are used and loaded |
| In-between heading sizes, labels from 9.9px to 12.5px | Fixed. Four font sizes in total (section 3) |
| Spacing off the 8px grid | Fixed. Every rem spacing value is a multiple of .5rem |
| Raw color values outside `:root` | Fixed. Scrims use `rgb(var(--bg-rgb) / a)`; photo plinths use `--paper` |
| Several accents visible on the home page | Open by design. Each card is scoped to one perfume |

Still true, and allowed:

- `.25rem` (4px) appears inside controls only. The burger icon lines sit on 4px steps.
- Separators between inline items use `em` margins so they scale with the text.
- `.label` text is 12px at weight 800; weight 200 is used once, for spec values (`.facts dd`).

How to re-check after a change: the stylesheet must contain no `font-weight` other than
200/400/800, no `font-size` outside the four values above, and no hex or `rgba()` color
below the `[data-p]` block.
