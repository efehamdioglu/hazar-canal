# DESIGN.md: Hazar Canal

Rules for every design change in this repo. Read this before touching `build.py` or
`site/assets/style.css`. If a request conflicts with a rule here, say so before building.

Revision 2 (2026-11-27). Revision 1 demanded 200/800 weight extremes, 3x size jumps and
square corners everywhere. Built faithfully, that produced a loud, generic page: fat
uppercase headings, tracked uppercase labels on every block, boxy outlined buttons, and
dots, dashes and arrows as decoration. Those rules are withdrawn. This revision replaces
them with the direction the owner asked for: quiet, specific, niche.

## 0. What this repo is

- Static HTML generated by `build.py` (Python, no dependencies), one stylesheet
  (`site/assets/style.css`), one script (`site/assets/app.js`). No `package.json`, no
  Tailwind, no React, no shadcn/ui. Do not add any of them to satisfy a rule.
- Pages are regenerated with `python build.py`. Never edit `site/*.html` by hand.
- Media lives in `site/media/`; `python fetch_media.py` downloads anything new and rebuilds.

## 1. The idea

A quiet catalogue for loud objects. The bottles, the films and the myths are dramatic;
the page around them is small, dark and still, like a reliquary case. If a change makes
the interface louder than the perfume it is showing, it is wrong.

## 2. Fonts

| Role | Family | Variable | Used for |
|---|---|---|---|
| Display | Libre Caslon Display | `--display` | Perfume names, headings, statements, quotes |
| Text | Sorts Mill Goudy (regular, italic) | `--text` | Everything read as prose; italics carry secondary meaning |
| UI | Jost 400 / 500 | `--ui` | Navigation, buttons, small captions, counters. Nothing else |
| Mono | none | | Not used. Do not add one for flavour |

- **Never use: Inter, Roboto, Open Sans, Arial, system-ui**, as a primary font or a fallback.
  Stacks end in a generic keyword only.
- **Mixed case, always.** Names are written "Şahmaran", not "ŞAHMARAN". Uppercase exists in
  exactly two places: the wordmark and `.cap` captions.
- One weight per serif (400). Emphasis is italic or size, never bold.
- Every font must cover Turkish (ş ğ ı İ ç ö ü). Check in the browser before proposing one.
- Foreign words inside uppercased text need `lang="en"` so `i` does not become `İ`
  (`tx()` and `EN_WORDS` in `build.py`).

## 3. Type scale

Seven sizes, all variables in `:root`. Do not write a raw `font-size`.

| Variable | Size | Use |
|---|---|---|
| `--fs-ui` | 13px | Jost: nav, buttons, captions |
| `--fs-small` | 16px | Notes under a name, captions, footer |
| `--fs-body` | 20px | Prose |
| `--fs-lead` | 24 to 40px | Statements and taglines |
| `--fs-head` | 36 to 64px | Section headings, note lists, quotes |
| `--fs-name` | 40 to 76px | Perfume names in lists |
| `--fs-hero` | 72 to 192px | One perfume name per page |

Large type is tight (negative tracking, line-height near 1); small type is open.

## 4. Color

All color is a CSS variable. No raw hex or `rgba()` below the `[data-p]` block.

- **One dominant:** warm black `--bg`. `--bone` is its inversion for one light section per
  page, not a second color.
- **One accent slot:** `--accent`, set by the perfume in scope through `[data-p="…"]`
  (Atlas bronze, Devil red, Barbaros teal, Şahmaran gold, Arora violet). One accent per
  component. A new perfume is one new `[data-p]` line.
- Accent is for a name on hover, a quote, a single line. Never a filled area.
- **Banned: purple or indigo gradients on white**, and decorative gradients of any kind.
  The only gradients are black scrims that keep text readable over photos and film.

## 5. Spacing and shape

- **8px rhythm.** Every rem spacing value is a multiple of `.5rem`. `.25rem` only inside a
  control.
- Layout is a 12-column grid with a 2rem gutter. Compositions are asymmetric: text sits on
  columns 1 to 7, images on 9 to 12, and one side is usually left empty.
- **Buttons are capsules** (`border-radius: 999px`), 48px tall, Jost 13px in sentence case.
  At most one filled button per view; everything else is an italic underlined `.link`.
- Images, cards and frames stay square-cornered. No shadows anywhere.

## 6. Ornament

- **No decorative punctuation.** No em dashes, middle dots, bullets, arrows, check marks or
  slashes as separators. Lists inside a line are sentences with commas. Separation between
  blocks is space or a 1px rule.
- **One ornament: the spear** (`.spear`), a hairline ending in a small diamond, taken from
  the spear in the logo. At most twice per page.
- Motion is slow and small: fades and 20px rises, about one second, `--ease`. Nothing
  bounces, nothing loops except film.

## 7. Components: reuse, do not hand-roll

**Python builders (`build.py`)**

| Function | Use it for |
|---|---|
| `page(fname, title, desc, body, accent, cur, ogimg)` | Every page shell |
| `header(cur)` / `footer()` | Navigation and footer. Never by hand |
| `buy(p, mode)` | Every purchase link. `full`, `one` or `row`. Handles the TR / INT split |
| `ext(href, label, cls)` | Every external link |
| `video(id, label, hero)` | Every film. Lazy, muted, plays only in view |
| `preview(p)` | A perfume's atmospheric image |
| `sentence(items)` / `all_notes(p)` | Note lists as comma sentences |
| `invite()` | The quiz invitation band |
| `im()`, `vid()`, `poster()` | Every media URL |
| `tx()`, `brandfix()` | Foreign words in Turkish text |

Data lives in `P` (one dict per perfume) and `QUIZ` / `WEIGHTS` / `RESULTS`. A new perfume
is a new dict, not new markup.

**CSS primitives (`site/assets/style.css`)**

| Class | Notes |
|---|---|
| `.wrap`, `.sec`, `.sec--tight`, `.sec--bone` | Gutter, section rhythm, the light section |
| `.hero-name`, `.name`, `.head`, `.lead`, `.small`, `.cap`, `.it` | The only text styles |
| `.btn`, `.btn--solid`, `.link`, `.acts` | The only actions |
| `.spear`, `.rule` | Ornament and divider |
| `.hero`, `.hero--split` | Full-bleed opening; split variant for vertical film |
| `.house` | Statement plus offset image plus four claims |
| `.index`, `.row`, `.index__stage` | The collection list with its hover-driven image stage |
| `.film`, `.films`, `.films__row` | Film tiles |
| `.split`, `.story`, `.facts`, `.love`, `.notes`, `.gallery`, `.craft` | Page sections |
| `.invite`, `.sister`, `.buybar`, `.seg`, `.sound`, `.opt` | Quiz band, prev/next, mobile buy bar, toggles, quiz option |

Behaviour in `app.js` is attribute-driven (`data-set-store`, `data-store`,
`video[data-src]`, `.rv`, `aria-controls="mega"`, `.row[data-i]`). Use those hooks.

## 7b. Languages

- Eight languages: Turkish at the root, `en/ it/ fr/ es/ de/ ar/ ja/` as folders. Every page
  exists in every language; the language menu links to the same page in the other language.
- **No text in `build.py` or in markup.** Every visible string is a key in `i18n/tr.json`
  (the source, taken from hazarcanal.com) and is read with `t("key")`. A new string means a
  new key in all eight files; `python check_i18n.py` must pass before building.
- Never translated: Hazar Canal, the perfume names, Extrait de Parfum, Eau de Parfum.
- **Language decides the shop.** Turkish pages show iyzico and Shopier; every other language
  shows Etsy, or Shopier where a perfume has no Etsy listing. There is no separate TR / INT
  switch.
- Arabic is right to left. Use logical properties only (`margin-inline-start`,
  `padding-inline-end`, `text-align: start`); never `left` / `right` for layout.
- Arabic and Japanese have no true italic and no letter-spacing: both are switched off for
  those languages in the stylesheet. Their fonts (Amiri, IBM Plex Sans Arabic, Shippori
  Mincho, Zen Kaku Gothic New) load only on those pages.
- Flags are the only colour that does not come from a perfume. They live in the language
  menu at 20px and nowhere else. Source: `flag-icons` (MIT), in `site/assets/flags/`.

## 8. Forbidden

- Three rounded cards in a row. The collection is a list, not a card grid.
- Centered-everything heroes. Heroes anchor bottom-left. Only the closing sign-off is centered.
- Drop shadows.
- An eyebrow label above every heading. `.cap` is for real captions and group names.
- Uppercase headings, bold serif, letter-spaced body text.
- Emoji as icons, glass panels, stock photos of ingredients, autoplaying sound, a second
  accent in one component, a second filled button in one view.

## 9. Re-checking after a change

- No `font-size` outside the seven variables (plus the two fixed sizes in `.mega` and `.craft`).
- No hex or `rgba()` below the `[data-p]` block.
- `grep` the built HTML for `—`, `·`, `→`, `✓`, `•`: only quiz answer text may contain them.
- All ten pages at 375px wide: no horizontal scroll.
